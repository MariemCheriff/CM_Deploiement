Service SOAP avec Python

Le service a une méthode say_hello qui retourne le message bonjour. Il utilise le protocole SOAP 1.1 et un serveur WSGI qui écoute sur le port 8000.

Pour installer les dépendances: 
1- pip install spyne lxml
2- lancez le serveur avec python server.py. Le service est accessible à l’adresse http://localhost:8000.
